
# 豆瓣电影Top250爬取与分析
# 项目介绍
这是一个豆瓣电影Top250爬取与分析项目，进行简单的数据爬取和分析代码编写
# 功能介绍
1.通过标签筛选指定内容并打印
2.如果标签内无内容时输出为None，无法通过text转文本，可以通过if判断填充文本，方便后续转文本
3.导演，主演，年份等大部分相连文本可以通过replace("\n","").strip().split()删掉大部分空格和\n，压缩为列表
4.通过循环，从前往后取列表元素，到"导演“处停，删掉已取出内容，因为主演中”/“数量不确定，所有将列表倒过来，从后往前取类型，国家，年份，更方便容易
5.新增了多页爬取功能，并运用time.sleep进行间隔防止被封
7.标签不明确的使用函数进行文本识别寻找指定数据
8.保存为xlsx格式
